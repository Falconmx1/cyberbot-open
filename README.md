# cyberbot-open

CyberBot Open es una herramienta de ciberseguridad conversacional, open source y colaborativa, que integra múltiples motores de IA y frameworks de chatbot. Ideal para desarrolladores y admins web, provee asesoría técnica avanzada con un fuerte enfoque ético: no ayuda en creación de malware ni software dañino.

## Características
- Multi-modelo: Rasa (Python), Botpress, Langchain.js + Mistral, GPT4All, DeepSeek, Copilot
- API REST y WebSocket para integración web
- Docker ready: instalación fácil y portátil
- Colaboración con otras IAs y chatbots
- Sin filtros, pero con protección ética anti-malware

## Instalación rápida
```bash
git clone https://github.com/tuusuario/cyberbot-open.git
cd cyberbot-open
docker-compose up --build
```
